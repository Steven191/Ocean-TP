# 2) 数据驱动时区划分方程

## 方法概述

- 统计小时残差按年内日序（day-of-year）构成 365 点曲线，使用循环动态规划确定 4 个最优断点（最小化段内残差方差）。
- 将得到的起止日期应用于全部年份数据，全量 QC=1 样本按划分聚合。
- 每个季节从原始 CSV 随机采样 20 万条记录，训练 8 项可解释基函数 PINN（损失 = 数据 MSE + λ_phys·PDE 残差 + L2 正则；λ_phys=0.5，λ_reg=1e-4，Adam 4000 步）。

# 3) 深度分层与精度

## 深度分层：从经验到数据-物理协同

- **目标**：层数保持 3（必要时拓展至 4），分界由观测信号与物理一致性共同决定，避免主观拍板。
- **多源信号**：
  - 温度梯度与曲率：$|\partial T/\partial z|$、$|\partial^2 T/\partial z^2|$ 的峰值通常对应跃层边缘。
  - 残差方差：分析当前模型残差 `r(z)` 的局部方差或分位区间，突升位置视作候选边界。
  - 输入分布漂移：比较不同深度段的压力分布（MMD/能量距离）；显著跳变提示断层。
  - 物理残差：PDE 残差随深度的异常抬升段需单独成层，方便后续物理修正与再标定。
- **候选边界**：将上述信号的峰值/突变点组合，取 Top-K（K 取 10-20）形成候选集合。

## 候选边界优化（固定三层）

在候选集合上使用动态规划求解最优 `{b_1,b_2}`，最小化段内数据误差、物理残差及层间平滑项：

```
\min_{b_1,b_2} \sum_{\ell=1}^{3} \left[ \mathcal{L}_{\text{val}}^{(\ell)} + \lambda_p \mathcal{L}_{\text{phys}}^{(\ell)} \right]
+ \lambda_s \sum_{\ell=1}^{2} \lVert \theta_{\ell+1} - \theta_{\ell} \rVert_2
```

- **约束条件**：限定最小层厚（例如 >=500 m）与层内样本下限。
- **输出**：`L1=[0,b_1]`，`L2=(b_1,b_2]`，`L3=(b_2,max]`。结果填写至 Excel `LayerBoundaries` 表，附带验证指标。
- **MoE 备选**：可训练以深度为门控输入的 3 专家 MoE，以主导概率给出初边界，再执行上述 DP 微调；方法记录补充至 `LayeringMethod` 表。

## 按层训练与评估

- **损失重加权**：总损失 $\mathcal{L} = \sum_{\ell} w_\ell \mathcal{L}_{\text{data}}^{(\ell)} + \lambda_p \mathcal{L}_{\text{phys}}$。建议初值 `w_L1=1.3`，`w_L2=1.0`，`w_L3=1.1`，并按验证 MAE 进行 $\propto 1/\text{MAE}^{(\ell)}$ 的归一化更新。
- **鲁棒损失策略**：
  - L1 噪声大，优先使用 Huber 或分位数损失，阈值 $\delta$ 针对层内分布调节。
  - L2/L3 可采用 MAE/MSE，并根据厚尾程度单独设定 Huber $\delta$。
- **逐层指标**（记录在 `LayerMetrics` 表）：
  - 精度：MAE / MAPE / R²（TimeSeriesSplit，报告均值±标准差）。
  - 置信区间：MAE 95% CI（自助或分块 bootstrap）。
  - 不确定性：`PICP_90`/`PICP_95`、`MPIW_95`、ACE、NLL（MC Dropout 或 Ensemble）。
  - 传感器偏差：拟合 `bias(P)=c_0 + c_1 P (+ c_2 P^2)`，用 AIC/BIC 选型，结果填入 `SensorBiasModel` 表。

## 建议起跑线

- L1：0-1000 m（浅层/混合层）：扰动与季节性强，提升权重并优先采用鲁棒损失。
- L2：1000-3000 m（中深层）：数据平稳、信息密度适中，维持基准权重。
- L3：3000-6000 m（深层）：温变弱但高压，留意传感器系统误差与校准；如有 >6000 m 数据，可扩展 L4：6000-11000 m。

## 可视化与报告建议

- 层 x 指标热力图：展示 MAE/MAPE/R²/NLL 随层变化。
- 层内残差分布：直方图与 QQ 图用于检查残差形态是否接近正态或厚尾分布。
- 偏差-压力曲线：各层 `bias(P)` 拟合及置信带。
- 覆盖率曲线：`PICP` 与置信水平的关系，并附校准曲线。
