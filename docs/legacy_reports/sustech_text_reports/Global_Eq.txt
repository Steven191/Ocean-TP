# 1) 全部数据的通用方程

## 数据与预处理
- 数据源：`/Users/Zhuanz/Desktop/ooi` 目录下全部 `ooi-*.csv`，共 27,107,765 条 QC=1 记录。
- 关键列：时间 (`time`)、温度 (`sea_water_temperature_profiler_depth_enabled`)、质量控制 (`sea_water_temperature_profiler_depth_enabled_qc_agg`)、深度 (`z`，向下为负)。
- 处理流程：
  1. 逐个文件按 400k 行分块读取，跳过第二行单位信息。
  2. 只保留 QC 聚合值为 1 的样本，并用 `depth_m = -z` 转为正深度。
  3. 丢弃温度或深度为 NaN/Inf 的记录；其余保留原始温度值（单位 °C）。

## 尝试过的特征组合

| 形式 | 描述 | 全量指标 (MAE / RMSE / R²) |
| ---- | ---- | -------------------------- |
| 多项式 (z 的 2~6 次) | 纯归一化多项式特征 | 0.2118 / 0.3928 / 0.8036 (二次)<br>0.1481 / 0.3120 / 0.8761 (四次) |
| 采样拟合 | 基于 ≤ 100k 抽样直接 `polyfit` | 在全量数据上偏差较大，外推不稳 |
| 混合数学特征 | `ln(P), sqrt(P), 1/P, exp(-P/τ)` 等组合 | 多组测试 RMSE 0.1119~0.1172，R² 0.982~0.984 |
| Chebyshev 多项式 | `T₀` 至 `T₇` 基函数 | 0.0548 / 0.1164 / 0.9828 |
| 分段 ReLU (Spline) | 基于阈值的 `(P-k)+` | 0.0541 / 0.1160 / 0.9829 |
| Sigmoid 梯度 | 多个 logistic 过渡项 | 0.0520 / 0.1127 / 0.9838 |

综合比较后，选择能兼顾浅层变化、深层渐近和数值稳定性的 8 项混合函数作为最终方案。

## 最终 8 项通用方程
令压力/深度 `P` (单位 dbar ≈ 米，取自 `depth_m`)：

MAE ≈ 0.05107 °C, RMSE ≈ 0.11189 °C, R² ≈ 0.98407

```
T̂(P) = -356.873
        + 0.0125047 · P
        + 62.2025   · ln(P)
        - 3.35576   · sqrt(P)
        + 20.0563   · exp(-P / 500)
        + 14.8832   · exp(-P / 1200)
        + 10011.3   · 1 / (P + 50)
        + 7576.48   · 1 / (P + 500)
```

> 说明：`ln` 为自然对数；`sqrt` 以 dbar 的平方根为单位；指数项与倒数项的尺度选取用于刻画浅层混合层、穿越热跃层后的过渡，以及深海冷水的平滑衰减。

## 历史方程版本（均以 P 为单位 dbar）

## 模型评估（全量 QC=1 数据）

- 样本量：27,107,765
- 平均绝对误差 (MAE)：0.05107 °C
- 均方根误差 (RMSE)：0.11189 °C
- 决定系数 (R²)：0.98407

对比前述候选方案，该方程在 RMSE 与 R² 上取得最优或并列最优，同时保持闭式表达，便于快速计算。

## 使用建议
1. 输入压力/深度 `P` (dbar ≈ 米) 到方程中即可获得温度估计 `T̂`。
2. 若用于超出当前数据范围的极浅 (P < 150 dbar) 或极深 (P > 4000 dbar) 区域，可额外加上边界校验或与观测数据混合。
3. 对于需要更细分的空间/时间依赖，可在此基础上引入分区或季节性修正。
