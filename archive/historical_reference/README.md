# Historical Reference Materials

This folder keeps earlier experiment deliverables, draft-stage materials and older reference figures. These files are retained for traceability and are separated from the current manuscript-support records.

## Included Folders

- `experiment_02_upper_200m_sampling/` - upper-200 m sampling and coefficient comparison deliverables.
- `experiment_03_coefficient_rounding/` - coefficient rounding sensitivity deliverables.
- `experiment_04_thermocline/` - thermocline-focused error-profile deliverables.
- `experiment_06_interannual/` - interannual depth-profile and error-statistics deliverables.
- `figures/` - older reference figures.
- `manuscript_drafts/` - draft-stage manuscript documents retained as historical context.
- `presentations/` - compact historical presentation/PDF reference files.

The current reviewer-facing records are indexed in `docs/DATA_INDEX.md`.
